# Product Vision

## Thesis

AoA Spine 1.0 should become a local-first, low-VRAM, evidence-bounded
multi-agent operating spine for repository work.

The differentiator is not generic autonomy. The differentiator is disciplined
execution on weak hardware with grounded evidence control.

## Core Promise

AoA Spine should do four things well:

1. ingest a repository or work surface into a structured memory spine
2. retrieve the smallest sufficient evidence for a request
3. route compact evidence packets to specialized agent lanes
4. refuse, spill, or compress before consumer hardware is overrun

## What It Is Not

- not a general-purpose autonomous swarm
- not a cloud-first browser-heavy platform
- not a prompt pack pretending to be a runtime
- not a benchmark theater project without proof

## Product Principles

- local-first by default
- cheap hardware is a first-class target
- evidence before answer
- packet before full context
- refusal is a feature, not a failure
- benchmarks must measure real retrieval and grounding quality

## Main User Surfaces

1. local CLI for repository indexing and grounded query flows
2. shared runtime contracts for multi-agent routing
3. evaluation harness for retrieval and grounding regressions
4. optional demo surface for review and adoption

## North Star Question

Can AoA Spine improve grounded task success per GB of available memory while
reducing context waste and hallucination pressure?
